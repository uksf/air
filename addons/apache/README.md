# Apache

Apache conversion with custom functions and configurations.

## Engine and rotor sound sources

The layers inherit the JSRS 2025 AH-64 sound sets and replace only their recordings.

- `rotor_ext.ogg`, `rotor_int.ogg`, `turbine_ext.ogg`, `turbine_int.ogg`: "KC0504T2.WAV" by Tuig, CC BY 4.0, https://freesound.org/s/47918/
- `rotor_dist.ogg`, `turbine_dist.ogg`: "apache heli on 400m city 141212_00.wav" by klankbeeld, CC BY 4.0, https://freesound.org/s/257633/
- `rotor_echo.ogg`: "high Apache AH 64 attack helicopters sanctuary Rijskampen s-Hertogenbosch Netherlands 1053 am 260116_0068" by klankbeeld, CC BY 4.0, https://freesound.org/s/842367/
