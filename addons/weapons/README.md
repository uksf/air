# Weapons

Weapons for F-35

## M230 sound sources

The M230 layers inherit the JSRS 2025 small autocannon sound shaders and replace only their recordings. Every distance layer shares one Mk44 core so the layers blend as the listener moves away.

- Mk44 Bushmaster II core: "Automatic Cannon - MK44 - 03 - Single Shot with Report 03" by Fascinated Sound, The Gun Locker SFX Pack, Sonniss GDC 2016 Game Audio Bundle, royalty free
- M230 attack: "m230_chain_gun_burst_1" to "m230_chain_gun_burst_4" by qubodup, CC0 1.0, https://freesound.org/s/67560/ to https://freesound.org/s/67563/
- Range recording in the close distance, medium, and far layers: US Army AH-64 gunnery footage, DVIDS videos 461540 and 965319, public domain
